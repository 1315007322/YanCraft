# ruoyi-blog 设计留痕

本模块每次需求都要在这里记一笔：**为什么这么设计、做了什么、刻意没做什么**。

Maven 构件版本跟若依父工程（当前 3.9.2）。**功能版本**独立编号，写在 `CHANGELOG.md` 和 `versions/` 下。

## 当前功能版本

**1.0.1**（2026-09-18）— [设计说明](versions/v1.0.1.md)

历史：

- [1.0.0](versions/v1.0.0.md) 模块首版

## 新需求怎么留痕

1. 在 `CHANGELOG.md` 增加一节，版本号按 SemVer：
   - 新能力 / 新表字段：`MINOR`（1.1.0）
   - 仅修复或不改对外契约：`PATCH`（1.0.1）
   - 不兼容变更（改接口路径、改状态码含义、删字段）：`MAJOR`
2. 复制 `versions/_template.md` 为 `versions/vX.Y.Z.md`，写清需求来源、方案取舍、影响的表和接口。
3. 改本页「当前功能版本」指向新文件。
4. 若有 DDL，放 `sql/cms_vX.Y.Z.sql`，只含相对上一版的增量。
