# v1.3.0 友链管理

- 日期：2026-09-20
- 需求来源：后台增加友链管理：昵称、描述、网站地址、启用、排序
- 功能版本：1.3.0（MINOR）

## 要解决什么

在若依后台维护博客友情链接，可启用/停用并按排序展示。

## 设计考虑

- 表名 `cms_friend_link`，`status` 0 启用 / 1 停用，`del_flag` 逻辑删除。
- 管理页走弹窗 CRUD，路径 `/cms/link`，菜单 `cms/link/index`。
- 网址必须 `http://` 或 `https://`；未删除记录中 `site_url` 唯一。
- 前台只读 `/portal/cms/link/list` 仅返回启用友链；本版不做前台友链页。
- 不做图标上传、分类签约、申请审批流。

## 数据变更

- 表：`cms_friend_link`
- 菜单：2004、2040-2043
- SQL：[sql/cms_v1.3.0.sql](../sql/cms_v1.3.0.sql)

## 接口变更

- 新增后台：`GET/POST/PUT/DELETE /cms/link`
- 新增前台：`GET /portal/cms/link/list`

## 实现要点

- `CmsFriendLinkController` 权限 `cms:link:*`
- 管理端 `views/cms/link/index.vue`
