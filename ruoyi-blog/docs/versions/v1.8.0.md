# v1.8.0 列表封面与详情头图

- 日期：2026-10-08
- 需求来源：首页列表要 1:1，详情顶部要横向宽图
- 功能版本：1.8.0（MINOR）

## 要解决什么

一张图很难同时服务列表方图和详情横幅，需要两套封面。

## 设计考虑

- cover 继续给首页列表，1:1
- 新增 coverWide / cover_wide 给详情顶部，16:9 宽图
- 缺省回退：列表优先 cover，详情优先 coverWide
- 不做一张原图自动裁切两份，构图差太多
- AI 生成按目标分别要 1024x1024 和 1792x1024
