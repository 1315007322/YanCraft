# v1.12.0 考公言语积累

- 日期：2026-10-14
- 功能版本：1.12.0（MINOR）

## 要解决什么

考公言语题要每天刷实词成语、关联词和主旨句。后台自己录卡，前台每天固定一组卡来刷，也能随机抽一张看。

## 设计考虑

- 新增独立模块 `ruoyi-exam`，表 `exam_verbal_card` 存卡片，`exam_verbal_daily` 存每天的卡组
- 卡片分三类：实词成语、关联词、主旨句；正面写词或句子，背面写差别、搭配、易混点和自己的一句
- 每天 0:05 按到期时间排出今日卡组，最多 20 张；后端启动时也会补排一次
- 复习间隔按 1、3、7、14、30 天推进；点「还没记住」的卡推到明天，每张卡每天只能推一次
- 前台菜单由站点配置 `verbalEnabled` 控制；页面有今日卡组、全部卡片、类型筛选、搜索和随机一张
- 三类卡片样式分开：成语用米字格，关联词用逻辑链，主旨句用划线笔记
- `exam_verbal_idiom_seed.sql` 导入 393 张成语速记口诀卡

## 其他改动

- 股票复盘「复制上一日」跳过没写内容的日子，同时带入结论、失误和下一步计划
- 后台文章列表按修改时间倒序
- 前台 Markdown 引用块加上底色和左侧竖线

## 上线步骤

1. 执行 `ruoyi-exam/sql/exam_v1.0.0.sql`
2. 按需执行 `ruoyi-exam/sql/exam_verbal_idiom_seed.sql`
3. 重新发布后端和前台，在站点设置里打开「言语积累」
