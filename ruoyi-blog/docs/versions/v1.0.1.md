# v1.0.1 代码注释与中文编码

- 日期：2026-09-18
- 需求来源：方法和 Controller 补方法注释
- 功能版本：1.0.1（PATCH）

## 要解决什么

后台/前台接口和业务方法缺少 JavaDoc，阅读成本和后续改需求时对不齐设计说明。同时发现模块内中文注释、校验提示、异常信息出现乱码。

## 设计考虑

- 注释风格对齐若依：类上说明职责，方法上说明「做什么 / 关键约束」，Service 接口补 `@param` / `@return`。
- 不把设计文档全文搬进代码，细节仍以 `docs/versions` 为准。
- 乱码按 UTF-8 重写源文件（与 `pom.xml` 的 `project.build.sourceEncoding` 一致），避免运行时校验文案和异常对用户不可读。
- 不改 SQL、不改 URL、不改状态机，所以记 PATCH 而不是 MINOR。

## 数据变更

无。

## 接口变更

无对外契约变化。`CmsConstants.MODULE_VERSION` 调整为 `1.0.1`。

## 实现要点

- 四个 Controller、三个 Service 接口、四个 Mapper、三个 ServiceImpl、实体与 `ArticleReadingStats` 补注释
- 顺带修复异常/校验中文

## 验证

- [x] 源文件中文注释可读
- [ ] 编译通过（随本次改动）

## 编码说明

源文件一律 UTF-8（与若依其它模块、Maven project.build.sourceEncoding 一致）。
若 IDE 仍显示乱码，多半是按 GBK 打开了 UTF-8 文件：右下角编码改为 UTF-8，必要时选 Reload。
