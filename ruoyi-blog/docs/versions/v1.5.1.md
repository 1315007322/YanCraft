# v1.5.1 后台 Markdown 编辑器

- 日期：2026-09-22
- 需求来源：个人博客后台 MD 编辑器使用 @yancraft/vue 组件库
- 功能版本：1.5.1（PATCH）

## 要解决什么

文章正文和「关于我」原先是纯文本框，编辑 Markdown 没有高亮和预览。

## 设计考虑

- 复用已有 @yancraft/vue 的 CodeEditor（language=markdown, mode=split），不另接一套编辑器。
- 包入口会带上 ant-design-vue，后台只用 Element Plus，因此 Vite 别名指向源码里的 CodeEditor，避免把 Ant 拉进后台。
- 后台封装 MarkdownEditor，文章页和站点配置共用。
- 不改文章存储格式，仍保存原始 Markdown。
