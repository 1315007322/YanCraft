# v1.11.0 前台 SEO

- 日期：2026-10-10
- 功能版本：1.11.0（MINOR）

## 要解决什么

搜索结果和分享卡片能用上文章标题、摘要和封面，并提供站点地图。

## 设计考虑

- 标题统一为「页面标题 · 站点名」，首页只用站点名
- 描述优先用文章摘要，否则用站点一句话
- Open Graph 和 Twitter 卡片带上封面；文章页加 BlogPosting 结构化数据
- 站点地址优先用站点配置里的 siteUrl，没填则用当前访问域名
- `/sitemap.xml` 收录首页、文章、分类、标签、复盘；`/robots.txt` 指向它
- 搜索结果页 noindex
