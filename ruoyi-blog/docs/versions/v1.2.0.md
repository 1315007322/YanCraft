# v1.2.0 博客前台 Nuxt 骨架

- 日期：2026-09-20
- 需求来源：确认技术栈 Nuxt 3 + Vue 3 + TypeScript
- 功能版本：1.2.0（MINOR）

## 要解决什么

给已发布文章一个独立阅读站，不和若依管理端混用。

## 设计考虑

- 独立 `ruoyi-blog-web`，SSR 走 Nuxt，接口仍是 `/portal/cms`。
- 视觉走纸本杂志风（稻色纸 + 朱砂色），不用 Element Plus。
- Markdown 关闭 html 选项；详情优先 slug。
- 首版不做评论、RSS、全文检索。

无 DDL。
