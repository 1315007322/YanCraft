# v1.5.2 前台 Markdown 表格展示

- 日期：2026-09-28
- 需求来源：前台预览文章时表格内容没有展示出来
- 功能版本：1.5.2（PATCH）

## 要解决什么

文章详情页能解析 Markdown 表格，但缺少边框和滚动容器，宽表在中间栏会被裁切，看起来像没渲染。

## 设计考虑

- 继续用 markdown-it 内置 GFM table，不放开原始 HTML。
- 给 table 补边框、表头底色，并用 `.md-table` 包一层横向滚动。
