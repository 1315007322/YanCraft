# v1.1.0 博客管理端页面

- 日期：2026-09-18
- 需求来源：blog 模块对应的前端页面还没完成
- 功能版本：1.1.0（MINOR）

## 要解决什么

后端文章/分类/标签接口已就绪，管理端菜单组件路径是 `cms/article/index` 等，但 `ruoyi-blog-admin-ui` 里没有对应页面，点菜单会 404。

## 设计考虑

- 页面风格对齐若依现有 CRUD（公告、岗位）：查询栏、工具按钮、表格、弹窗，不另做视觉体系。
- 正文继续用 Markdown 多行输入，不用公告页的 HTML 编辑器，避免和后端字数统计规则冲突。
- 封面复用全局 `ImageUpload`，走 `/common/upload`。
- 发布/下线做独立按钮，对应 `cms:article:publish` / `cms:article:offline`。
- 分类、标签下拉一次拉 500 条，首版够用，不做远程搜索。

## 数据变更

无 DDL。依赖已有字典 `cms_article_status` 和菜单 SQL。`CmsConstants.MODULE_VERSION` 调整为 `1.1.0`。

## 接口变更

无新后端接口。前端调用已有 `/cms/article`、`/cms/category`、`/cms/tag`。

## 实现要点

- `ruoyi-blog-admin-ui/src/api/cms/*`
- `ruoyi-blog-admin-ui/src/views/cms/{article,category,tag}/index.vue`

- [ ] 分类、标签可增改删
