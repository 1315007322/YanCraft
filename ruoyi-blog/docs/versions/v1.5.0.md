# v1.5.0 实验室项目管理

- 日期：2026-09-21
- 需求来源：后台增加实验室模块：项目名称、仓库地址、预览地址、封面
- 功能版本：1.5.0（MINOR）

## 要解决什么

在若依后台维护实验室项目卡片数据，并在博客前台通过独立菜单和卡片页展示。

## 设计考虑

- 表名 `cms_lab_project`，字段对齐需求：名称、描述、仓库 URL、预览 URL、封面。
- 额外保留排序、启用/停用、逻辑删除，与友链一致，便于隐藏和下线。
- 封面走现有 `/common/upload`（OSS 或本地），库中存返回的 URL。
- 仓库地址必填且必须 http(s)；预览地址可空。
- 前台增加 `/lab` 页面，双列卡片展示封面、项目名称、项目描述、仓库和在线预览入口。
- 站点配置增加 `labEnabled`，统一控制左侧“实验室”菜单是否显示。
- 不做 README 抓取、GitHub API、标签分类。

## 数据变更

- 表：`cms_lab_project`
- 站点配置：`labEnabled`
- 菜单：2006、2060-2063
- SQL：[sql/cms_v1.5.0.sql](../sql/cms_v1.5.0.sql)

## 接口变更

- 新增后台：`GET/POST/PUT/DELETE /cms/lab`
- 新增前台：`GET /portal/cms/lab/list`（仅启用项）

## 实现要点

- 权限 `cms:lab:*`
- 管理端 `views/cms/lab/index.vue`，列表风格与友链相同
- 门户端 `pages/lab.vue`，沿用站点编辑式卡片视觉
