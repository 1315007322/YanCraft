# v1.10.0 复盘展示与标签热力

- 日期：2026-10-10
- 功能版本：1.10.0（MINOR）

## 要解决什么

前台复盘列表和详情按复盘习惯排版，标签按文章数做成热力，文章编辑可以不滚到底就保存。发布时避免打进过期的后台包，并在 Docker 引擎无响应时自动拉起。

## 设计考虑

- 站点配置按冷静、乐观、谨慎、追涨、恐慌五档上传列表封面
- 列表不展示摘要，只显示日期、情绪、纪律、笔数和当日收益；收益为当天交易盈亏合计，盈绿亏红，零为持平，未填为未记
- 详情顶部同样展示当日收益；正文按结论、失误、下次计划、交易分卡片
- 标签云按已发布文章数着色，数量为 0 的保持浅色
- 文章编辑页确定、取消固定在内容区底部
- `publish.cmd` 打包前删除旧的 `ruoyi-admin.jar`，构建镜像前探测并必要时重启 Docker Desktop
