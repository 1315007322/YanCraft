# ruoyi-task 个人任务管理

独立的个人任务模块，面向当前登录用户提供“主任务 + 一级子任务”的计划管理。

## 当前版本

**1.0.1**（2026-09-21）

- 设计说明：[versions/v1.0.1.md](versions/v1.0.1.md)
- 数据脚本：[../sql/task_v1.0.0.sql](../sql/task_v1.0.0.sql)

## 核心规则

- 每条数据必须绑定当前登录用户，接口不接受前端传入的所属用户。
- 只允许两级任务，子任务不能继续创建下级。
- 叶子任务手动维护进度；主任务存在子任务时，按子任务进度等权平均。
- 主任务删除时逻辑删除其子任务。
- 逾期由截止日期和任务状态实时判断，不保存冗余字段。
