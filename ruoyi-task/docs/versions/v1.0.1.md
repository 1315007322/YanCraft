# v1.0.1 任务数量进度

- 日期：2026-09-21
- 功能版本：1.0.1

## 目标

叶子任务支持按“总量 / 已完成数量”自动计算进度，例如网课 100 集已看 21 集。

## 数据设计

- 表：`task_item`
- 新增字段：`total_quantity`、`completed_quantity`
- 进度规则：
  - 有子任务：仍按子任务等权平均
  - 无子任务且 `total_quantity > 0`：`round(completed_quantity * 100 / total_quantity)`
  - 其余叶子任务：继续手工维护进度

## 接口

- 沿用 v1.0.0 全部接口
- 新增 `PUT /task/item/{taskId}/quantity`

## 迁移

已建库执行 `ruoyi-task/sql/task_v1.0.1.sql`。

## 验收重点

- 未跑增量脚本的旧表会报 `Unknown column 't.total_quantity'`
- 已填写总量的任务不能再手工改百分比
- 已完成数量不能大于总量
