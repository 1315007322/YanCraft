# v1.0.0 个人任务管理

- 日期：2026-09-21
- 功能版本：1.0.0

## 目标

在若依后台集中维护个人规划任务，清楚看到主任务、子任务、当前进度、优先级和截止时间。

## 数据设计

- 表：`task_item`
- 层级：`parent_id = 0` 为主任务，其余记录只能指向主任务。
- 隔离：`owner_user_id` 始终由登录态写入和过滤。
- 进度：叶子任务手动维护；填写总量后按已完成数量换算；有子任务的主任务取所有未删除子任务进度的等权平均值。
- 字典：`task_status`、`task_priority`

## 接口

- `GET /task/item/list`
- `GET /task/item/statistics`
- `GET /task/item/root-options`
- `GET /task/item/{taskId}`
- `POST /task/item`
- `PUT /task/item`
- `PUT /task/item/{taskId}/progress`
- `PUT /task/item/{taskId}/quantity`
- `DELETE /task/item/{taskIds}`

## 边界

- 不支持无限层级。
- 不支持多人协作、附件、提醒、重复任务和看板拖拽。
- 已取消任务保留当前进度，不计为已完成。

## 验收重点

- 不能访问或修改其他用户的任务。
- 子任务更新或删除后，主任务进度同步变化。
- 有子任务的主任务不能手工修改进度。
- 删除主任务时一并逻辑删除其子任务。
